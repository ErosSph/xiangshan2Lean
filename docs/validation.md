# v0.2 实际验收结果

状态：PASS。结构化汇总见 validation.json，完整日志在各 experiments 目录。

- 51 个不同的真实 Chisel 模块自动生成参数化 Lean，均通过 Lean 4.19.0 检查。
- 128 个参数配置与独立官方 RTL 对照通过。
- 共执行 6303 个输入周期，比较 28907 个接口输出值。
- 25 项不支持构造、非法参数域及未定义轨迹检查均按预期拒绝。
- 对隔离副本故意把 Counter 输出加一，差分测试在首个复位后输出发现
  Lean=1、RTL=0；正常交付模型未被修改。
- 原 Scala 后端的 9 个上游示例重新编译通过。
- README 的公开 Counter 翻译、PowerShell 入口和执行示例实际运行通过。
- examples/CounterProof.lean 的输出等于状态和禁用时保持两条模型定理通过检查。
- 四组完整差分配置及源码、生成模型、运行时、验证驱动的当前指纹全部匹配。

构造覆盖包括：不同位宽及有符号运算、回绕、截断/扩展、同步旧状态、
连接优先级、嵌套 when/elsewhen/otherwise、使能/复位、输入决定的复位值、
部分复位、参数分支的条件位宽与合法域、零宽 UInt、Vec/生成循环和命名 IO。
扩展覆盖参数化多层模块、Bundle 寄存器、RegNext/RegEnable、强制字面值
别名、隐式位宽推导、部分生成区间、动态数组读写、Enum/switch、不同
Mux 优先级、有符号除法及余数、动态左移、head/tail/Fill 和纯硬件辅助函数。

组合设计回归包含 FIFO、寄存器文件、异步读 Mem、一拍读 SyncReadMem。
FIFO 深度包含 2/3/8，数组长度包含 1/2/3/8；宽端口包含 65/128 位。
同步存储器读口禁用和读写同址的未定义输出会被仿真接口拒绝。
未复位状态在差分实验中显式设为零，与 Verilator 二态初始化对齐；
没有据此为 Chisel Mem 宣称零复位或确定的上电状态。

小组合配置穷举输入，较大配置采用固定种子的随机输入；Counter 配置
经过完整计数回绕。没有把上述结果描述为所有参数的形式化等价证明。

曾出现的构建、命名映射和并发 jar 读取问题保留在早期实验目录；发布
验收目录和这里的统计只采用修正后成功完成的运行。历史首版汇总保留于
validation-v0.1.json 和 validation-v0.1.md。当前结构化汇总由
scripts/report.py 对完整配置集合及实际 SHA256 指纹检查后生成。
