# Chisel2Lean4 v0.2 语义契约

输入是 Chisel 3.5.6 / Scala 2.13.10 的顶层、直接继承 Module 或
RawModule 的类及其构建依赖。转换在 Scala typer 后进行，不固定构造参数。
输出是可执行 Lean 4.19.0 定义与版本化、带类型及来源的 IR。

## 参数和合法域

`Params` 保存 Scala Int / Boolean 参数。Int 用 Lean Int 表示，`valid p`
包含有符号 32 位取值范围、源 require、宽度/索引/字面值合法条件。
源 Int 的 +、-、*、/、%、负号按两补码 32 位回绕；除法向零取整。
BitVec 宽度从合法整数转 Nat。
UInt 宽度允许零；首版显式声明的 SInt 宽度至少为一。

Chisel 3.5.6 的 KnownWidth 使用 Int，并拒绝负值。IR 对已支持的
硬件宽度计算检查 0..2147483647；非扩展加减与取负还检查其源 API
内部的扩展临时结果，避免把源工具中溢出失败的配置当作合法电路。
字面值用最少表示位数检查适配，不为验证合法域构造巨大的 2^width。

`valid` 是执行前必须满足的契约。CLI 在运行前检查它；用户直接调用
生成的 step/output 时也必须确保它为 true。它不是翻译正确性证明。

## 组合连接和状态

先保留源连接顺序，将每个目标的最终驱动归并成条件表达式，后续连接
覆盖前面的连接。然后解析组合信号引用，因而 `b := a` 读取 a 的最终
组合驱动。未完整连接的组合量和组合环会报错，包括没有输出使用的量。

寄存器引用始终读取旧 `State`。所有 next 字段同时从旧状态和当前输入
计算，不能按代码顺序立即覆盖寄存器。没有连接的寄存器保持。

`output p inputs state` 返回当前组合输出。
`step p inputs state reset` 返回一个上升沿后的状态。
比较边沿后输出时使用 `output p inputs (step p inputs state reset)`。

## 复位与初态

时序支持范围是标准顶层 Module 的单时钟、同步、高有效 Bool 复位。
RegInit 的复位值在 reset 有效边沿覆盖普通更新。没有复位值的寄存器
仍按源连接更新，不被统一清零。withReset、异步/自定义复位和多时钟拒绝。

只有所有寄存器的复位值均明确且不依赖旧寄存器时，才生成
`resetState p inputs`；它表示在给定输入下经历有效复位边沿后的状态。
它不是上电初始化。部分复位和 Reg/RegEnable 的未知状态需要调用方
显式提供 State。组合电路的 State 是空结构。

## 宽度、符号与条件

非扩展加减宽度是操作数最大宽度；扩展加减再加一；乘法宽度为两者之和。
计算在运算结果宽度处回绕，然后按连接目标进行截断或扩展。
UInt 零扩展，SInt 按有符号值扩展。有符号比较和算术使用 toInt。
强制转换保持位模式；Bool 单独表示。混合 UInt/SInt 算术需要显式转换。

硬件 Mux 的位向量结果宽度取两个分支的最大值。
Scala 生成时 if 保留条件，并在临时量位宽不同的时候使用条件宽度。
生成分支中字面值等的合法性检查受相同生成条件保护；硬件 when 的
两个生成分支都必须合法。参数控制的 IO/寄存器声明布局尚未支持。

未强制宽度的标量节点、寄存器和 Wire 建立单调宽度约束，从最小合法
位宽求固定点。复位初值、普通连接和被后续连接覆盖的赋值都参与约束。
扩展运算反馈没有有限固定点时拒绝；声明明确宽度可限定此类反馈。
RegInit 的强制字面值保持指定宽度；非强制字面值和非字面值标量遵循
源 API 的推导规则。RegNext 推导标量宽度，聚合类型保留元素布局。

Vec 用 `Fin length -> element` 表示。until 循环变为逐元素函数，部分
区间保留其他元素的已有连接。循环合法条件以有限范围的全称检查进入
valid，不固定构造参数。索引及局部别名使用独立绑定名，避免实例和
循环变量捕获。元素类型/位宽必须统一，循环不能创建新的状态布局。

动态 UInt 索引按 Chisel truncateIndex 规则，仅保留 log2Ceil(length)
位；长度一固定选择元素零。截断后的索引仍越界时，模型的执行前置
条件为 false。标量动态位选择等价于动态右移后取位零。

MuxCase/PriorityMux 优先选择前面的真条件。MuxLookup 后面的匹配
覆盖前面的匹配；字面值键覆盖完整空间时，按源 API 去掉默认值的
位宽影响。运行时 Mux 使用统一宽度；生成时条件保留条件宽度。

## 模块层次

先收集依赖模块和 Bundle 定义，再按需要解析。每个实例以父模块的
参数表达式替换子参数，内部信号/寄存器加实例前缀。子模块的 require
及合法域也被替换并并入父域。子输入和输出成为内部连续连接，父接口
保持原来的端口。所有层级的寄存器在同一边沿同时读取旧状态更新。
模块源码需要可用；不调用任意 Scala 运行时来猜测缺失的语义。

## 存储器与未定义结果

Mem 表示无复位的存储状态函数，读是组合访问，单写端口在边沿更新。
SyncReadMem 另有一拍读结果寄存器及有效标志；读使能和地址决定下一拍
结果。默认 Undefined 模式下，同一边沿的读写同址不产生有效读结果。
读口被禁用后的读结果也无有效保证。当前不接受多写端口、掩码写入、
显式不同读写冲突模式或不同端口时钟。

outputDefined 和 transitionDefined 是可执行的 Bool 条件，沿 Mux、
生成函数和有效读路径传播。UInt/SInt 除数必须非零；有符号除法向零
取整，余数与被除数同号。定义本身是总函数；在 FIRRTL 未规定结果的
区域，函数返回的数值不构成硬件语义保证。CLI 检查这些条件并拒绝
未定义的观察，避免把填充值当成确定硬件结果。

存储器需要显式初始状态。--warmup 仅允许第一拍边沿前未定义，随后
观察必须定义。差分驱动使用显式零状态与 Verilator 的二态初始化配置
对齐；这个实验条件不表示 Chisel 的 Mem 有零复位或确定上电状态。

## 证据的含义

Lean 类型检查确认输出程序可接受。仿真确认测试配置的可执行行为。
独立参考从原始 Chisel 源码经官方 Chisel/FIRRTL 生成 RTL，再用
Verilator 比较接口。参考不使用我们的 IR 或表达式解释器。
首次有效复位/暖机边沿前的 RTL 未知状态不参与状态电路比较。
有限配置、随机序列和小输入穷举均不构成所有参数的形式化等价证明。
